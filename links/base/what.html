What is this?

Lèu Fish is a personal project and website built using static HTML and a bit of CSS. It contains no JSON or JavaScript. It is not intended to become a popular website; I simply made it for the fun of it.

I don't plan to update it frequently. Most of the time, updates will be major ones covering a significant portion of the website.

If you want to explore or fork this website, its source code is available on GitHub under the AGPL-3.0 license. You can find the repository in the options submenu below the website's logo. That's also where you'll find the LICENSE and CONTENT LICENSE files.

Compatibility

This website is designed to run on relatively low-powered or older hardware. All it requires is an internet connection and a browser capable of supporting modern HTML and CSS.

This means it won't work with absolutely every old browser, but any browser that supports current HTML and CSS should be able to display it.

The website was also built entirely as a static site to ensure compatibility and portability across different devices.

What can you find here?

As mentioned on the homepage, this website is a collection of my interests and experiences with FreeBSD, Linux, free softwar, and open-source projects.

About my tutorials

You'll also find tutorials, recommendations (covering software, protocols, privacy, tools, and services), and various tools.

I believe that when writing tutorials about FreeBSD or Linux, testing things on real hardware provides a much better and more accurate experience.

That's about it! Thank you for reading this far!
